Domain Model

Domain adalah bahasa inti aplikasi. Di project ini, domain menyimpan tipe seperti user, team, project, task, enum role, pagination, notifikasi, dan error aplikasi.

Apa itu domain?

Domain adalah bagian yang menjelaskan konsep bisnis tanpa tergantung HTTP atau database. Contoh: Task adalah konsep bisnis, sedangkan query SQL untuk mengambil task adalah detail store.

Contoh model task

type Task struct {
    ID          int           `json:"id" db:"id"`
    Title       string        `json:"title" db:"title"`
    Description *string       `json:"description" db:"description"`
    Status      TaskStatus    `json:"status" db:"status"`
    Priority    *TaskPriority `json:"priority" db:"priority"`
    ProjectID   int           `json:"projectId" db:"project_id"`
    Comments    []CommentView `json:"comments,omitempty" db:"-"`
}

Kenapa field ada pointer?

Description *string berarti deskripsi bisa kosong secara semantik, bukan hanya string kosong. Ini penting saat database punya nilai NULL. Pada input update, pointer juga membantu membedakan "field tidak dikirim" dan "field dikirim dengan nilai kosong".

Enum sebagai tipe khusus

Role dan status task biasanya disimpan sebagai string, tetapi lebih aman jika dibungkus tipe khusus seperti domain.UserRole, domain.TaskStatus, dan domain.TaskPriority.

type UserRole string
type TaskStatus string
type TaskPriority string

Dengan tipe khusus, signature function jadi lebih jelas. HasRole(actor.Role, domain.RoleProjectManager) lebih mudah dibaca daripada membandingkan string mentah di banyak tempat.

Generic pagination

Project punya tipe generic untuk response list:

type Paginated[T any] struct {
    Data       []T        `json:"data"`
    Pagination Pagination `json:"pagination"`
}

Tanpa generic, kita mungkin perlu membuat banyak tipe seperti UserListResponse, TaskListResponse, dan ProjectListResponse. Dengan generic, satu tipe cukup.

Pemakaian Arti
domain.Paginated[domain.User] Data berisi slice user.
domain.Paginated[domain.Task] Data berisi slice task.
domain.Paginated[domain.Project] Data berisi slice project.

Error domain

Folder domain juga menyimpan error aplikasi. Tujuannya agar handler bisa mengubah error menjadi HTTP status yang konsisten. Misalnya error forbidden menjadi status 403, not found menjadi 404, dan validation menjadi 400.

Prinsip: domain boleh tahu konsep bisnis, tetapi jangan biarkan domain tahu detail Gin, sqlx, PostgreSQL, cookie, atau header HTTP.

Latihan

  1. Buka internal/domain/user.go, lalu cari field yang punya tag json dan db.
  2. Buka internal/domain/enums.go, lalu catat role dan status yang tersedia.
  3. Buka internal/domain/pagination.go, lalu jelaskan dengan kata sendiri apa arti T any.
