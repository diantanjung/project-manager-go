Bab 01

Gambaran Besar Project

Project ini adalah backend REST API untuk aplikasi manajemen project. Ia mengurus user, login, role, team, project, task, komentar, attachment, notifikasi, dan penyimpanan PostgreSQL.

Masalah yang diselesaikan

Aplikasi project manager biasanya punya alur seperti ini: user login, user membuat team, project manager membuat project, task dibuat untuk project, anggota team diberi tugas, lalu sistem mengirim notifikasi. Backend ini menyimpan semua data itu dan mengatur siapa boleh melakukan apa.

Teknologi utama

Teknologi Peran
Go Bahasa backend. Cocok untuk API karena sederhana, cepat, dan punya standard library kuat.
Gin HTTP router dan middleware. Dipakai di internal/httpapi.
PostgreSQL Database utama. Skema dibuat lewat file SQL di migrations.
sqlx + pgx Akses database. sqlx memudahkan scan row ke struct, pgx menjadi driver PostgreSQL.
JWT Access token dan refresh token untuk auth.

Alur request

Bayangkan client memanggil endpoint POST /api/tasks. Request berjalan melalui layer berikut:

  1. internal/httpapi/router.go menentukan route dan middleware.
  2. internal/httpapi/task_handler.go membaca JSON request dan mengambil user dari context Gin.
  3. internal/service/task_service.go menjalankan validasi dan aturan role.
  4. internal/service/store_interfaces.go mendefinisikan kontrak method database yang dibutuhkan service.
  5. internal/store/postgres/task_store.go menjalankan query PostgreSQL.
  6. internal/httpapi/response.go mengubah hasil atau error menjadi response JSON.
Client
  -> Gin Router
  -> Handler
  -> Service
  -> Store interface
  -> PostgreSQL implementation
  -> JSON response

Konsep Go yang akan muncul

  • Package: setiap folder Go adalah unit organisasi kode.
  • Struct: dipakai untuk model data seperti domain.Task dan konfigurasi seperti config.Config.
  • Interface: dipakai oleh service untuk menyatakan kebutuhan ke layer store.
  • Pointer: field seperti *string menunjukkan data opsional atau nullable.
  • Generic: domain.Paginated[T] bisa dipakai untuk banyak tipe data.
  • Error wrapping: error diberi konteks dengan fmt.Errorf("...: %w", err).
  • Context: context.Context membawa cancellation dan deadline dari HTTP request ke database.
Target setelah bab ini: kamu tahu backend ini dibagi menjadi beberapa layer, dan bisa menjelaskan jalur data dari HTTP request sampai database.
