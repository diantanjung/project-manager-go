Bab 12

Recap: Sudah dan Belum

Bab terakhir merangkum apa yang sudah dibuat dalam folder tutorial, apa yang sudah dijelaskan, dan apa yang belum dibahas mendalam.

Yang sudah dibuat

  • Folder doc/tutorial berisi dokumentasi HTML yang bisa dibuka di browser.
  • File index.html sebagai daftar isi.
  • Bab terpisah dari 01 sampai 12.
  • File style.css agar semua bab punya tampilan konsisten.

Materi yang sudah dibahas

Topik Status Bab
Tahapan development project Selesai untuk alur utama 01, 02, 03, 11
Struktur folder Go Selesai 03
Package, struct, pointer, receiver, error, context Selesai untuk dasar membaca project 04
Interface dan pemisahan service-store Selesai 06
Generic Selesai untuk contoh pagination 04, 05, 09
Dependency injection Selesai untuk manual constructor injection 07
HTTP API dengan Gin Selesai untuk routing, handler, middleware 08
PostgreSQL store dan migrasi Selesai untuk konsep dan helper utama 09
Auth, JWT, refresh token, RBAC Selesai untuk alur utama 10
Testing dan debugging Selesai untuk workflow dasar 11

Yang belum dibahas mendalam

  • Detail semua endpoint satu per satu beserta contoh payload lengkap.
  • Detail seluruh file migrasi dan relasi antar tabel secara diagram ERD.
  • Implementasi upload file secara mendalam.
  • Strategi deployment production, Docker, CI/CD, dan observability.
  • Benchmark dan performance profiling.
  • Security audit lengkap seperti rate limiting, CSRF, secret rotation, dan threat modeling.

Urutan belajar lanjutan

  1. Jalankan project lokal sampai /health berhasil.
  2. Baca internal/domain sambil mencocokkan dengan tabel migration.
  3. Baca satu fitur lengkap, misalnya task: handler, service, interface, store, migration.
  4. Tulis test kecil untuk satu service method.
  5. Tambahkan field kecil di task sebagai latihan: domain, migration, input, store, handler, test.
Kesimpulan: project ini adalah contoh bagus untuk belajar backend Go karena memakai layer yang jelas, manual DI, interface untuk testability, generic untuk pagination, Gin untuk HTTP, dan PostgreSQL sebagai persistence nyata.
