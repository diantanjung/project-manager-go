Bab 02

Setup Development

Bab ini menjelaskan langkah menjalankan project secara lokal: dependency Go, konfigurasi environment, database, migrasi, seed, server, dan test.

Prasyarat

  • Go sesuai versi di go.mod: go 1.26.5.
  • PostgreSQL berjalan lokal atau remote.
  • Database URL dalam bentuk postgres://user:password@host:port/dbname?sslmode=disable.

Environment

Server membaca konfigurasi lewat internal/config/config.go. File .env akan diload jika ada. Variabel paling penting adalah DATABASE_URL.

DATABASE_URL=postgres://postgres:postgres@localhost:5432/project_manager?sslmode=disable
PORT=3000
FRONTEND_URL=http://localhost:5173
JWT_SECRET=replace-me
JWT_REFRESH_SECRET=replace-me-too

Di kode, nilai fallback diberikan oleh helper getenv:

func getenv(key string, fallback string) string {
    value := os.Getenv(key)
    if value == "" {
        return fallback
    }
    return value
}

Install dependency

go mod download

Perintah ini membaca go.mod dan go.sum, lalu mengambil dependency seperti Gin, sqlx, migrate, JWT, dan bcrypt.

Database command

Project punya command helper di cmd/db. Dari README, urutan lokal yang umum adalah:

go run ./cmd/db ping
go run ./cmd/db migrate-up
go run ./cmd/db seed
Command Tujuan
ping Memastikan aplikasi bisa connect ke PostgreSQL.
migrate-up Menjalankan file SQL *.up.sql di folder migrations.
seed Mengisi data demo dari cmd/db/demo_seed.sql.

Run server

go run ./cmd/server

Entry point server ada di cmd/server/main.go. Fungsi run melakukan wiring: load config, buka database, buat token manager, buat service, buat router, lalu start HTTP server.

svc := service.New(postgres.New(db), tokenManager)
router := httpapi.NewRouter(cfg, svc)

Cek API

curl http://localhost:3000/
curl http://localhost:3000/health

Run test

go test ./...

./... berarti semua package di module ini. Ini cara cepat memastikan perubahan tidak merusak package lain.

Kesalahan umum: kalau server gagal dengan pesan DATABASE_URL is required, berarti environment belum terbaca. Pastikan .env berada di root project saat menjalankan command.
