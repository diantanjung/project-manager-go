PostgreSQL Store

Store adalah implementasi persistence. Service hanya tahu interface, sedangkan package internal/store/postgres tahu detail sqlx, query SQL, table, dan kolom.

Struct Store

type Store struct {
    db *sqlx.DB
}

func New(db *sqlx.DB) *Store {
    return &Store{db: db}
}

*sqlx.DB adalah pool koneksi database. Ia aman dipakai bersama oleh banyak request.

Membuka koneksi

func Open(ctx context.Context, databaseURL string) (*sqlx.DB, error) {
    db, err := sqlx.Open("pgx", databaseURL)
    if err != nil {
        return nil, fmt.Errorf("opening database pool: %w", err)
    }
    db.SetMaxOpenConns(25)
    db.SetMaxIdleConns(10)
    db.SetConnMaxLifetime(5 * time.Minute)

    if err := db.PingContext(ctx); err != nil {
        db.Close()
        return nil, fmt.Errorf("pinging database: %w", err)
    }
    return db, nil
}

Helper query

Project punya helper untuk pagination, where clause, update clause, dan not found handling.

func paginated[T any](data []T, filter service.PageFilter, total int) domain.Paginated[T] {
    return domain.Paginated[T]{
        Data: data,
        Pagination: domain.Pagination{
            Page:       filter.Page,
            Limit:      filter.Limit,
            TotalItems: total,
            TotalPages: service.TotalPages(total, filter.Limit),
        },
    }
}

Ini contoh generic di layer database. Helper yang sama bisa membungkus list user, list project, atau list task.

Builder WHERE

type whereBuilder struct {
    parts  []string
    values []any
}

whereBuilder menyusun potongan SQL dan argumen. Ia membantu membuat filter dinamis tanpa menyusun nomor parameter PostgreSQL secara manual di setiap query.

Mapping SQL ke struct

Field domain punya tag db agar sqlx tahu kolom mana masuk ke field mana:

ProjectID int `json:"projectId" db:"project_id"`

Error database ke error domain

func notFound(err error) error {
    if err == nil {
        return nil
    }
    if errors.Is(err, sql.ErrNoRows) {
        return domain.ErrNotFound
    }
    return err
}

Dengan helper ini, service dan handler tidak perlu tahu sql.ErrNoRows. Mereka cukup memahami domain.ErrNotFound.

Migrasi

Folder migrations berisi file up dan down. File up membuat perubahan schema, file down membatalkannya. Nomor prefix menjaga urutan eksekusi.

000001_create_enums.up.sql
000002_create_updated_at_function.up.sql
000003_create_users.up.sql
...
Hal yang harus hati-hati: query dinamis harus tetap memakai parameter binding. Jangan memasukkan input user langsung ke SQL string, kecuali nilainya sudah dipilih dari whitelist seperti nama kolom sort.
