Tutorial Development Project Manager Go

Dokumentasi ini dibuat per bab supaya bisa dibuka langsung di browser. Fokusnya dua: memahami tahapan pembuatan backend ini dan memahami konsep Go yang muncul di kode nyata.

Cara memakai tutorial

Buka file ini di browser, lalu ikuti bab secara berurutan. Setiap bab punya tujuan, potongan kode, dan latihan kecil. Jalur belajarnya sengaja dimulai dari setup, lalu struktur, konsep bahasa, layer aplikasi, database, auth, dan testing.

Untuk pemula Go

Mulai dari bab 01 sampai 04. Jangan buru-buru ke database sebelum paham package, struct, pointer, interface, generic, dan error.

Untuk memahami project

Fokus bab 05 sampai 10. Di sana dijelaskan alur request dari Gin handler, service, store interface, PostgreSQL, sampai response.

Untuk praktik harian

Gunakan bab 11 sebagai daftar perintah yang sering dipakai: test, run server, migrasi, curl, dan cara membaca error.

Peta bab

Bab Isi utama File project yang dibahas
01 Tujuan project, fitur, dan alur backend README.md
02 Setup Go, env, PostgreSQL, migrasi, run server cmd/server/main.go, cmd/db/main.go
03 Layout Go: cmd, internal, domain, service, store Seluruh folder utama
04 Package, function, struct, pointer, slice, map, error, context, generic Contoh dari beberapa layer
05-10 Implementasi domain, service, DI, HTTP, database, auth, RBAC internal/...
11-12 Testing, debugging, checklist selesai dan belum *_test.go, recap tutorial
Catatan: tutorial ini menjelaskan kondisi project saat file dibuat. Jika kode berubah, bagian yang paling mungkin perlu disesuaikan adalah daftar endpoint, role permission, migrasi, dan struktur service/store.
